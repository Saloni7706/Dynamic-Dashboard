# 📊 Dynamic Dashboard (Frontend Assignment)

This project is a **Dynamic Dashboard Application** built using **React and Context API**.  
It allows users to **create categories, add/remove widgets dynamically, and search widgets** across categories in real time.  
The UI is styled with modern, professional CSS to give it an enterprise dashboard look.

---

## 🚀 Features

- 📌 JSON-like structure for categories & widgets  
- ➕ Add new categories and widgets dynamically  
- ❌ Remove categories or widgets easily  
- 🔍 Search bar to filter widgets across all categories  
- 🎨 Professional responsive UI with hover effects & animations  
- ⚛️ State managed using React Context + useReducer  

---

## 🛠 Tech Stack
- React (CRA)  
- React Context API + useReducer  
- CSS3
